# DrivePNG Rentals Website

## Project Overview
This is the integrated final website for **IS229 Web Design Assessment 4**.  
The project demonstrates semantic HTML5, CSS3 responsive design, JavaScript interactivity, accessibility features, and GitHub collaboration.

## About This Repository
- **Main Branch:** Integrated site
- **Feature Branches:** Each member works on their own branch (e.g., `member-2-about-page`)
- **Deployment:** GitHub Pages (static hosting)

## Member Responsibilities
- **Member 1:** Home Page (HTML, CSS, JS, responsive design)
- **Member 2:** About Page (HTML, CSS, JS toggle feature, responsive design)
- **Member 3:** Vehicles/Products – Structure & Design (HTML, CSS, responsive layout)
- **Member 4:** Contact Page (HTML, CSS, JS validation)
- **Member 5:** Login/Register Page (HTML, CSS, JS validation/interactions)
- **Member 6:** Vehicles/Products – Functionality (JavaScript filtering/search)

## Technologies Used
- HTML5
- CSS3 (Flexbox, Grid, responsive design)
- Vanilla JavaScript
- Git + GitHub
- GitHub Pages (deployment)
